# Step 4 実装計画

Goal: エディターをSlack登録ダイアログに組み込み、生成したFileと名前を反映する。
Spec: ../specs/2026-10-31-slack-emoji-extension-design.md

- [x] view.jsをmountEditor(root, options)として再利用可能にし、破棄時にURLを解放する。
- [x] adapter.jsで専用data-qa、同一フォーム、一意性、表示・接続状態を確認する。
- [x] 画像と名前を渡し、Slackプレビューと保存状態を観測する。部分反映やタイムアウトを成功扱いしない。
- [x] content.jsでShadow DOMにマウントし、開閉に追従する。編集内容をメモリで保持し、離脱時に監視を解除する。
- [x] manifestとローカルビルドを用意し、権限を登録ページに限定する。
- [x] ブラウザfixtureで曖昧な対象、再生成、二重UI、再反映、失敗を確認する。
- [x] 実Slack確認用の成果物と手順を用意する。Chromeへの追加は必要ならユーザーへ依頼する。

技術選択: ビルドはローカルモジュールだけを順序固定で結合する。import/exportの対応形式を限定し、未知の形式はビルドを失敗させる。外部コード・外部通信・永続保存・自動登録を追加しない。
