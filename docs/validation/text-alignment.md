# 文字揃え（0.4.0）

フォント選択の下に「文字揃え」のselectを追加。中央（初期値）・左・右を選べる。プレビュー・PNG生成・Slack反映に同じalign値を使い、下書きにも保持する。

文字の実際の輪郭と太字補正を含む境界を基準とし、左は8px、右は120px、中央は64pxを基準に揃える。縦方向の中央配置と全行共通のサイズ調整は維持する。不正なalign値は拒否する。

## 検証

- Nodeテスト8件成功。新規テストでは、長さの違う行の左端・中央・右端の座標、初期値と中央指定の一致、不正値の拒否を確認。
- Chromeのtests/alignment.htmlで4書体×3揃えの12ケースが成功。2行の実画素から左右端・中央の座標を測り、余白・画像寸法・容量・欠けがないことを確認。並べた画像も目視確認した。
- tests/slack-browser.jsに文字揃えの変更と開き直し後の保持確認を追加。縦伸縮追加時に検証専用ブラウザで再実行し、右揃えの下書き保持も含めて合格を確認した。
- distと配布ZIPを0.4.0へ更新。実Slackで新しい選択欄を使うには拡張とSlackページの再読み込みが必要。新バージョンでのSlack保存操作は今回行っていない。
