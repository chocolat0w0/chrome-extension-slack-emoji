# 縦伸縮（0.5.0）

「縦に伸ばして埋める」チェックボックスを文字揃えの下に追加。初期値オン。文字を透過Canvasに描画し、alphaのある最上段〜最下段を検出して、上下8pxの余白内（112px高）へ縦に伸ばす。横方向の配置・幅は維持し、背景色は最終Canvasに別描画する。オフでは従来の縦横比と配置を維持。選択は下書きにも保持する。

検証専用ブラウザで4書体×3揃え×1行／2行の24組（On/Off計48PNG）を確認。Onの文字範囲はy=8〜119、Offは元の高さ、画像端の欠けなし。省略時と明示的OnのPNG一致、背景色の保持も確認。既存統合10項目も成功し、初期OnとOff選択の下書き保持を追加確認。Nodeテスト9件成功。通常のChrome操作と競合したため、実Slackへの追加登録は行わず専用ブラウザの模擬フォームで確認した。

## 輪郭の改善（0.6.3、2026-11-01）

画像を拡大する処理を廃止し、文字の実メトリクスと輪郭幅から縦範囲を計算して、Canvasの変換を設定したうえで文字を直接描画する方式に変更。背景は別描画し、文字レイヤーは等倍で合成する。上下8pxの描画範囲を維持する。細い横線・句読点のラスタライズでは、輪郭が境界より最大1px内側になることを許容する。オフの処理は維持。

独立したヘッドレスChromeの実Canvasで次を確認した。

- 長い一行（「三」12文字）の輪郭回帰テストは修正前に失敗、修正後に成功。最初の文字の水平線を通るx=12列では、半透明画素が112→6、不透明画素が0→76となった。比較画像でも「ありがとう」と長い水平線の輪郭改善を目視確認。
- 5書体×3揃え×12入力の180組（On/Off計360PNG）。1〜4行、先頭・途中・末尾の空行、英字の上端・下端、細い横線・句読点を含む。上下余白、画像端の欠け、PNG寸法・容量、初期On、背景色を確認。
- 旧描画コードとの比較で、オフ時のPNGが5書体×3揃え×2背景×4入力の120組すべて一致。
- 既存実Canvas8ケース、文字揃え15ケース、5書体10PNG、色設定、模擬Slack統合10項目、回帰9項目が成功。フォント検証の書体数が4固定だったため、現在の5書体すべての描画が異なることを検証するよう更新。
- Nodeテスト10件成功、構文検査と差分の空白検査も成功。ビルドと0.6.3配布ZIPの内容一致検証が成功。

実Slackへの反映・保存は行っていない。利用時は拡張機能とSlackページの再読み込みが必要。
