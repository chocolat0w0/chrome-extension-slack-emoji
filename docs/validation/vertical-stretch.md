# 縦伸縮（0.5.0）

「縦に伸ばして埋める」チェックボックスを文字揃えの下に追加。初期値オン。文字を透過Canvasに描画し、alphaのある最上段〜最下段を検出して、上下8pxの余白内（112px高）へ縦に伸ばす。横方向の配置・幅は維持し、背景色は最終Canvasに別描画する。オフでは従来の縦横比と配置を維持。選択は下書きにも保持する。

検証専用ブラウザで4書体×3揃え×1行／2行の24組（On/Off計48PNG）を確認。Onの文字範囲はy=8〜119、Offは元の高さ、画像端の欠けなし。省略時と明示的OnのPNG一致、背景色の保持も確認。既存統合10項目も成功し、初期OnとOff選択の下書き保持を追加確認。Nodeテスト9件成功。通常のChrome操作と競合したため、実Slackへの追加登録は行わず専用ブラウザの模擬フォームで確認した。
