# 自由な色設定（0.6.0）

既存のカラーピッカーに加え、文字色・背景色にHEX入力欄を追加。#RRGGBB、#RGBと#なしの入力を受け付け、正規化して描画する。ピッカー・HEX・プリセットは同期。不正な文字列や入力途中ではプレビューを消し、生成・反映を止め、入力欄にaria-invalidと案内を表示する。背景透過時は背景色入力を無効にし、選んだ背景色は保持する。下書き復帰でもカスタム色を保持する。

検証専用ブラウザで、HEX→ピッカー、ピッカー→HEX、プリセット同期、入力エラー、短縮HEX、背景透過切替、下書き保持を確認。生成したFileをPNGとしてデコードし、文字色#EC71A1と背景色#123456の画素を確認した。初回テストでは古いモジュールのキャッシュで入力欄が見つからなかったため、テストブラウザのHTTPキャッシュを無効化して最新コードで確認した。

既存の統合10項目・回帰9項目、Nodeテスト10件も成功。幅320pxと560pxで横方向のはみ出しがないことを確認。実Slackへの追加登録は今回行っていない。
