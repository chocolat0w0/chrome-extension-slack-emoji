# Chrome ウェブストア掲載文

## 短い説明

Slackの登録画面で文字絵文字の作成から登録まで行えます。

## 詳細な説明

Slackのカスタム絵文字登録画面で、文字絵文字の作成から登録まで行えます。画像をダウンロードして選び直す必要はありません。文字や見た目を調整し、プレビューを確認してSlackの登録欄に反映したら、同じ画面で保存できます。

- 3種類の書体と3段階の太さ
- 文字色・背景色
- 文字揃えと縦伸ばし
- 丸囲み、二重丸、集中線のフレーム
- バウンド、ぶるぶる、ポップ、点滅のアニメーションGIF（速度調整可能）

【使い方】

1. PC版ChromeでSlackワークスペースにログインします。
2. アドレスバーに `https://<ワークスペース名>.slack.com/customize/emoji` を入力し、カスタム絵文字登録ページを開きます。
3. 「カスタム絵文字を追加する」を押し、文字絵文字を作成します。
4. 名前を入力して「登録欄に反映」を押し、Slack側のプレビューを確認して「保存する」を押します。

PC版Chromeの日本語Slackカスタム絵文字登録ページで動作します。Slackへのログインと、ワークスペースの絵文字追加権限が必要です。Slackが提供・承認する拡張機能ではありません。

画像はすべてブラウザ内で生成し、拡張機能の運営者が用意したサーバーへ入力文字・登録名・生成画像を送信することはありません。登録時は、利用者の操作により生成画像と名前をSlackの登録欄へ反映します。フォントはGoogle Fontsから取得し、入力文字そのもの・登録名・生成画像はGoogle Fontsに送信しません。
