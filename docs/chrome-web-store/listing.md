# Chrome ウェブストア掲載文

## 短い説明

Slackの登録画面で文字絵文字を作成します。

## 詳細な説明

Slackのカスタム絵文字登録画面で、文字絵文字を作成できます。文字や見た目を調整し、プレビューを確認してからSlackの登録欄に反映します。最後の保存はSlack画面で行います。

・4種類の書体
・文字色・背景色
・文字揃えと縦伸ばし
・丸囲み、二重丸、集中線のフレーム
・バウンド、ぶるぶる、ポップ、点滅のアニメーションGIF

PC版Chromeの日本語Slackカスタム絵文字登録ページで動作します。Slackへのログインと、ワークスペースの絵文字追加権限が必要です。Slackが提供・承認する拡張機能ではありません。

入力した文字・登録名・生成画像はブラウザ内で処理し、利用者が指定したSlackの登録欄へ反映します。
