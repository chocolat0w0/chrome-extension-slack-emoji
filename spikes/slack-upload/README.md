# Step 2の検証専用拡張

製品コードではなく、生成したPNGを既存のSlackフォームに渡せるか確認するための最小構成です。依存パッケージとビルドは不要です。

拡張自身には直接のネットワーク通信、永続保存、ダウンロード、フォーム送信、保存ボタンの自動クリックを行う処理はありません。ただし、画像と名前の入力イベントに反応してSlack側が通信や保存処理を行う可能性はあり、その動作は実機で未確認です。

1. Chromeの `chrome://extensions` を開き、デベロッパーモードで「パッケージ化されていない拡張機能を読み込む」を選ぶ。
2. このディレクトリ `spikes/slack-upload` を選ぶ。
3. Slackの `/customize/emoji` を再読み込みし、絵文字追加ダイアログを開く。
4. 「テスト画像と名前を反映」を押す。
5. Slack側の明暗プレビューと名前、保存ボタンの有効化を確認する。
6. テスト用ワークスペースで必要な1件を保存し、一覧に同名の絵文字が現れることを確認する。
7. 開き直し後にも反映できることを確認する。2件目の登録は不要。

Consoleからの実行はMAIN world相当の予備検証にとどまります。拡張を読み込んでISOLATED worldで動かした結果を、本検証の結果として記録します。
